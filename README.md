# Car Sales Analysis Dashboard

## Overview
Analysis of 23,906 car sales records across 
30 brands to uncover buyer behaviour, 
regional performance, and pricing trends.

## Key Insights
- Total revenue: $671,525,465
- Average selling price: $28,090
- Male buyers: 78.6% of all purchases
- Top-performing dealer region: Austin, at $117.2M in revenue — 10.2% higher than the next-highest region (Janesville) and 26.8% above the average of the other six regions
- Most expensive brand (by average selling price): Cadillac, at ~$40,972/vehicle
- Highest-volume brand: Chevrolet — 1,819 units sold and ~$47.7M in revenue, despite an average price ~6.7% below the overall average, indicating a volume-driven rather than premium-pricing position

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Microsoft Excel
