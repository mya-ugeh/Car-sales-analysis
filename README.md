# Car Sales Analysis Dashboard

## Overview
Analysis of 23,906 car sales records across 
30 brands to uncover buyer behaviour, 
regional performance, and pricing trends.

## Key Insights
- Total revenue: $671,525,465
- Average selling price: $28,090
- Male buyers: 79% of all purchases
- Austin was the highest performing 
  state at $117M in sales
- Chevrolet ranked as the most 
  expensive brand analysed

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Microsoft Excel
